# NetLog - 业余无线电中继点名记录工具

NetLog 是一款专为业余无线电爱好者设计的中继点名记录工具，该工具采用纯前端技术实现，所有数据存储在本地浏览器中。

## 功能特点

- **快速录入**：简洁直观的表单设计，支持键盘快捷操作，提高记录效率
- **智能提示**：输入框自动联想功能，支持拼音搜索，减少重复输入
- **数据字典**：可自定义管理QTH、设备、功率、天线等常用数据
- **呼号映射**：支持呼号与常用信息绑定，输入呼号自动填充关联数据
- **数据管理**：方便的日志查看、编辑、删除功能
- **数据导出**：支持导出Excel格式日志，便于后续分析和存档
- **数据备份**：支持字典数据导出备份，确保数据安全
- **明暗模式**：支持切换明暗主题，适应不同使用环境
- **响应式设计**：适配桌面和移动设备，随时随地记录通信日志

## 快速开始

1. 直接打开工具网页即可使用，无需安装
2. 首次使用建议先配置常用字典数据（QTH、设备等）
3. 在快速录入区域填写通信信息，按Enter键提交记录
4. 所有记录会实时显示在日志列表中

## 使用指南

### 1. 快速录入区域

快速录入区域位于页面左侧（移动设备上位于顶部），包含以下字段：

- **日期**：默认显示当前日期，可手动修改
- **时间**：自动记录当前时间，不可手动修改
- **操作员**：当前操作电台的操作员，支持字典提示
- **频率**：通信频率，默认438.900MHz，可修改
- **台网名称**：正在使用的中继或台网名称，支持字典提示
- **呼号***：通信对方的呼号，必填项，支持自动大写和字典提示
- **信号 (RST)**：信号报告，默认59，可修改
- **模式 (Mode)**：通信模式，默认FM，可选择其他模式
- **位置 (QTH)**：对方的地理位置，支持拼音搜索
- **设备 (Rig)**：对方使用的设备，支持字典提示
- **功率 (Pwr)**：对方的发射功率，支持字典提示
- **天线 (Ant)**：对方使用的天线，支持字典提示
- **备注 (Rem)**：其他需要记录的信息

**快捷操作**：
- 按Enter键可提交记录
- 输入时可使用上下箭头选择建议项，按Tab键填充
- 字段间按Enter键可快速跳转

### 2. 日志列表区域

日志列表区域位于页面右侧（移动设备上位于底部），显示所有已记录的通信日志，包含以下功能：

- 实时显示记录总数
- 表格形式展示所有记录，包含序号、日期、时间、呼号等信息
- 每条记录提供编辑和删除功能
- 支持通过"导出"按钮将日志导出为Excel文件

### 3. 数据与字典管理

点击"字典/数据管理"按钮可打开管理面板，包含以下标签页：

#### QTH字典
管理常用地理位置信息，支持：
- 批量导入：每行输入一个位置信息
- 单个添加：输入位置信息并点击"添加"
- 编辑：点击标签上的编辑图标，修改后点击"更新"
- 删除：点击标签上的删除图标

#### 设备字典
管理常用无线电设备信息，操作方式同QTH字典。

#### 功率字典
管理常用发射功率信息，操作方式同QTH字典。

#### 天线字典
管理常用天线类型信息，操作方式同QTH字典。

#### 操作员字典
管理常用操作员信息，操作方式同QTH字典。

#### 台网字典
管理常用中继或台网名称，操作方式同QTH字典。

#### 呼号字典
管理常用呼号信息，除基本操作外，还支持呼号映射功能：
- 点击"管理呼号映射"可打开呼号映射编辑器
- 格式：呼号[TAB]位置|设备|功率|天线|备注（备注可留空）
- 设置映射后，输入呼号时会自动填充关联信息

#### 日志数据
查看和管理所有日志记录，支持：
- 查看所有日志的详细信息
- 编辑每条日志记录
- 删除单条日志记录
- 清空所有日志记录
- 导出日志为Excel文件

### 4. 其他功能

- **切换明暗模式**：点击快速录入区域标题栏的月亮图标可切换明暗主题
- **导出字典**：点击日志列表区域的"导出字典"按钮可备份所有字典数据
- **清空日志**：点击日志列表区域的"清空日志"按钮可删除所有记录（需确认）

## 数据存储

所有数据（日志和字典）均存储在浏览器的本地存储中，不会上传到任何服务器，确保您的数据安全和隐私保护。

> 注意：如果清除浏览器数据或使用隐私模式，可能导致数据丢失。建议定期导出重要数据进行备份。
